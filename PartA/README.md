# Part A - Hack Computer

This part contains the Project 5 HDL chips:

- `CPU.hdl` executes Hack machine instructions.
- `Memory.hdl` connects RAM, screen memory, and keyboard input.
- `Computer.hdl` connects the CPU, memory, and instruction ROM.

Open the NAND2Tetris Hardware Simulator, select Project 5, and load these chips to run the course tests.
